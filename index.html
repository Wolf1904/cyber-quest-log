01 Campaigns

  
The TryHackMe learning paths, in play order. Set each one's status as you go. Completing a campaign earns 150 XP.

  

    
W1Weeks 1–3

      Foundation
      
Cyber Security 101

      Review networking, Linux, Windows, Active Directory, command-line tools, Nmap, HTTP, Burp Suite basics, and introductory exploitation. Since your knowledge is basic, use this path to close gaps; skip topics you can already demonstrate confidently.
      

    

  

  

    
W2Weeks 3–12

      Core VAPT
      
Jr Penetration Tester

      Focus on reconnaissance, Nmap, web enumeration, Burp Suite, SQL injection, XSS, SSRF, IDOR, authentication weaknesses, file inclusion, command injection, privilege escalation, Active Directory basics, and reporting.
      

    

  

  

    
W3Weeks 10–22

      AppSec specialization
      
Web Application Pentesting

      Deepen JWT and OAuth security, session handling, advanced injection, access control, insecure deserialization, SSRF, path traversal, race conditions, CORS, and source-code review. Tie each finding to a secure code fix.
      

    

  

  
Bonus world: Add the Offensive Pentesting path or targeted Windows/Linux labs after identifying infrastructure gaps. Don't rush through multiple paths just to collect completion badges.
